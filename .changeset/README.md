# Changesets

Este directorio es utilizado por [Changesets](https://github.com/changesets/changesets) para gestionar el versionamiento semántico de los paquetes de Forge UI.

## Uso

```bash
npx changeset        # Crear una intención de cambio
npx changeset version  # Aplicar versiones pendientes
npx changeset publish  # Publicar paquetes actualizados
```
